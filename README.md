# BrahMos explainer (work in progress)

A narrated "How BrahMos works" 3D explainer: research, script, Hinglish voice-over, FreeCAD airframe, Blender plates
and Motion Graphic overlays, produced on EngineX. Start with [HANDOFF.md](HANDOFF.md).
